# ArgoCD Application templates (adotantes)

Copie os manifests desejados para `clusters/production/apps/` no seu fork do [hinfra](https://github.com/gabehamasaki/hinfra) antes de aplicar o `root-app`, ou use `hinfra_deploy_public_gitops_examples: true` após copiar.

Produção com domínios reais: use o repo privado **hinfra-workloads** (não versione hosts reais no kit público).
