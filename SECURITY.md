# Security

If you discover a vulnerability in the **hinfra** kit (Ansible, manifests, CLI), please report it privately:

- GitHub: [Security Advisories](https://github.com/gabehamasaki/hinfra/security/advisories) on this repository
- Or email the maintainer via the contact on [hamasakis.dev](https://hamasakis.dev)

Do not open public issues for undisclosed security problems.

**Note:** Production app manifests and secrets belong in a **private** `hinfra-workloads` repository, not in this public kit.
